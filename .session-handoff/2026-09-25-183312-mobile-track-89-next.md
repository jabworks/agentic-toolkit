### Key discoveries

- **Fingerprint mechanics (Expo docs, via Context7).**
  - `@expo/fingerprint` has no compare-against-a-git-ref mode, so the precise check needs a fingerprint recorded after the last build. It records to condux working state.
  - Compare the `hash` fields; `fingerprint:diff`'s output when nothing changed is undocumented.
  - Only `expo-updates fingerprint:generate` takes `--platform`.
- **Held CI runs.** The changesets bot's Version Packages PRs arrive with CI at `action_required`. Approve with `gh api -X POST repos/jabworks/agentic-toolkit/actions/runs/<id>/approve`, then merge when green. Harvey approved this pattern for #171, #174 and #176.
- **The rsync quick-check bug.** `rsync`'s default size+mtime quick check skipped a same-size edit made in the same second as the previous copy (seen in a fresh worktree). Fixed with `--checksum` in `scripts/sync.sh`.
- **`sync.sh <skill>` syncs only that skill into `dist/plugins/`.** After editing several skills, run a bare `bash scripts/sync.sh`, or the mirror test fails.
