Design system · jabworks/agentic-toolkit

One system, four surfaces, zero dependencies.

The toolkit renders four HTML artifacts — a usage report, a handoff document, a plan reviewer, and a backlog board. Each ships self-contained: no CDN, no web fonts, no runtime dependency on the others. This is the system they share, and the page you are reading is rendered in it.

01 — the identity decision

Typography

Three of the four surfaces currently render all text in monospace at 13px, including prose. Rather than replace mono with sans, the system splits them by job: mono carries display and data, where it reads as deliberate and technical; sans carries prose and chrome, where monospace actively hurts reading. Every heading on this page is mono. Every paragraph is sans.

02 — unchanged

Colour

The existing palette is kept as-is: a warm charcoal ground rather than pure black, a warm cream light mode, and a single clay accent. Semantic colours stay separate from the accent. Nothing here is a proposal — it is what already ships, shown so the rest of the system can be judged against it.

Categorical colour — series identity, in fixed order. Distinct from the accent (a surface's voice, not a series) and from the semantics (a project is neither good nor bad). Computed for both surfaces, not picked: worst adjacent CVD ΔE 15.8 dark / 15.7 light, and all eight clear 3:1 on both grounds. Past slot 8 the hues repeat with a second channel; past 16 they fold to cat-other. See the specimen and decisions D7.

New: a third theme state. Today all four surfaces follow the OS and offer no override, so you cannot force light for a screenshot or dark in a bright room. The system adds [data-theme] over the existing prefers-color-scheme default, persisted in localStorage.

05

Motion & state

Three of the four surfaces have zero transition rules, and none has a prefers-reduced-motion block. Two of them have no focus styling at all. Everything below is in the shared kit:css region, so it lands once rather than four times. Tab through this page to see the focus ring.

Hover shifts colour over --dur-fast; press translates 1px on --ease-spring; focus-visible draws a 2px --ring with offset. Reduced motion collapses all of it.

07 — currently absent everywhere

Empty & loading

None of the four surfaces has an empty, loading or error state. A board with nothing on it, a report with no sessions, a dropped live-reload connection — all currently render as blank space.

The four surfaces

What each one inherits, and what stays its own. The shared regions are inlined byte-exactly by check-tokens.mjs — no runtime dependency, so every artifact stays self-contained and independently installable.

Sequencing. check-tokens.mjs compares byte-exactly, so a core change cannot be split per-plugin: the kit lands as one atomic all-four commit plus an npm changeset. The per-surface layout work follows as four independent, separately releasable changes.
