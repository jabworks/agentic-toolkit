# Cursor distribution channel

The toolkit's fourth distribution channel: Cursor consumes skills as native
SKILL.md (since Cursor 2.4) from a merged-trigger tree at
`dist/cursor/skills/`, generated by the shared variant builder. Docket's MCP
server registers on Cursor via `.cursor/mcp.json`.

Origin: docket #27 (2026-08-14) — "advertised, never tested".
