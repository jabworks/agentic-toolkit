## Patterns to follow

- **`DIRMODE`-gate every addition.** Single-file mode must render exactly as
  today.
- **Vanilla inline JS/CSS only** — the template is self-contained by
  test-enforced guarantee (no-egress, `skill-invariants.test.mjs`).
- **New CSS goes outside the `tokens:core` marker region**; colours come from
  the existing core tokens (`--muted`, `--muted-foreground`, `--primary`,
  `--border`…). Never hand-edit inside the markers.
- **Derive the tree from `docs[]`**, not a second directory walk — one source
  of truth for ordering (folder-grouped, `index.md` first).
- **Collapse state lives in memory** (a `Set` of open folder paths), seeded
  from the active doc's ancestors. No localStorage — sessions are short-lived
  review tabs.
- Match the file's existing style: no framework, `function` expressions as
  the surrounding code writes them, event handlers assigned like the
  neighbours do.
